# 残差（Residual）

> 一句话：残差 = "还差多少"。不直接预测答案，而预测答案相对参考值还需要修正的增量。
>
> 配套代码：`learningai/MLTest/residual_demo.py`（NumPy 最小可运行示例，含梯度校验）

---

## 1. 统计学 / 回归中的残差

### 1.1 定义

对第 $i$ 个样本，模型预测为 $\hat{y}_i$，真实观测为 $y_i$，则

$$e_i = y_i - \hat{y}_i$$

残差是**观测值与拟合值之差**。最小二乘（OLS）的目标就是让残差平方和（RSS）最小：

$$\text{RSS} = \sum_{i=1}^{n} e_i^2 = \sum_{i=1}^{n} \left(y_i - \hat{y}_i\right)^2$$

### 1.2 残差 vs 误差

| 概念 | 定义 | 能否观测 |
|---|---|---|
| 误差（error） | 真实值 − 真值 | 否，真值未知 |
| 残差（residual） | 观测值 − 预测值 | 是，可直接算 |

做模型评估时我们只能看残差，用它去**估计**误差的分布。

### 1.3 关键性质（线性回归，含截距）

记设计矩阵 $X$（已加一列 1），残差向量 $e = y - X\hat{\beta}$，由正规方程可得：

$$X^\top e = 0, \qquad \sum_i e_i = 0$$

即残差与所有特征（含截距列）正交、均值为 0。这两条性质常用来**检查代码是否写对**（见示例代码第 1 部分）。

### 1.4 用途：残差诊断

把 $e_i$ 对 $\hat{y}_i$ 或对某个特征画图（残差图）：

- 残差随机散布在 0 附近 → 模型大致合理；
- 呈 U 形 / 喇叭形 → 遗漏非线性项或存在异方差；
- 呈趋势 → 模型设定有偏。

### 1.5 与梯度提升（GBDT）的关系

GBDT 每一轮新增的树，拟合的是损失函数对当前预测的**负梯度**（伪残差）：

$$F_m(x) = F_{m-1}(x) + \nu\, h_m(x), \qquad h_m \approx -\frac{\partial L(y, F)}{\partial F}\bigg|_{F=F_{m-1}}$$

- 平方损失 $L=\tfrac12(y-F)^2$ 时，负梯度恰好等于 $y - F$，就是普通残差；
- 换成对数损失 / Huber 损失后，"残差"推广为负梯度，所以 GBDT 也叫"拟合残差的加法模型"。

## 2. 深度学习中的残差（ResNet）

### 2.1 要解决的问题：退化（degradation）

理论上网络越深表达能力越强，但实验发现：**普通（plain）网络堆到几十层后，训练误差反而比浅层网络更高**。这不是过拟合，而是优化困难——让一堆非线性层去学"恒等映射"（什么都不做）本身就很别扭。

### 2.2 残差学习

设某几层希望学到的理想映射是 $H(x)$。ResNet 不让它直接学 $H$，而让它学残差：

$$F(x) = H(x) - x \quad\Longrightarrow\quad H(x) = F(x) + x$$

实现上就是一条**捷径连接（shortcut / skip connection）**，把输入原样加到输出上：

```python
out = F(x) + x          # F 通常是 Conv-BN-ReLU-Conv
```

如果这几层什么都不用做，只要把 $F(x)$ 学到 0 即可（权重衰减、零初始化等让这很容易），比学恒等映射简单得多。

### 2.3 为什么有效（1）：梯度高速公路

把第 $l$ 层输入记为 $x_l$，残差块写作 $x_{l+1} = x_l + F(x_l)$，则

$$\frac{\partial x_{l+1}}{\partial x_l} = I + \frac{\partial F}{\partial x_l}$$

反传到第 $l$ 层的梯度为

$$\frac{\partial \mathcal{L}}{\partial x_l} = \frac{\partial \mathcal{L}}{\partial x_L}\left(1 + \frac{\partial}{\partial x_l}\sum_{i=l}^{L-1} F(x_i)\right)$$

括号里的 `+1` 意味着：**即使 $F$ 的雅可比很小（梯度消失），梯度仍能沿恒等通路无损回传**。这是缓解梯度消失、让上百层网络可训练的最直接解释（ResNet 原文的"gradient highway"）。

### 2.4 为什么有效（2）：恒等映射的易学性

在退化场景中，最优解往往接近"恒等映射"。残差形式下，恒等映射对应 $F \equiv 0$，是优化器最容易到达的解；而 plain 网络要把 $H \equiv \text{id}$ 拟合成一堆非线性层的复合，难度高得多。

### 2.5 残差块结构

标准（post-activation）残差块：

```
x ──┬── Conv 3×3 ── BN ── ReLU ── Conv 3×3 ── BN ──(+)── ReLU ──> out
    └──────────────────── shortcut ───────────────┘
```

**维度不匹配时**（通道数变化 / 特征图下采样），捷径不能直接相加，需要投影：

$$y = F(x) + W_s x,\qquad W_s \text{ 为 } 1\times1 \text{ 卷积（stride 与主路一致）}$$

这就是"投影捷径（projection shortcut）"；维度一致时直接用恒等捷径即可（参数更少，效果一样好）。

**瓶颈结构（bottleneck）**：1×1 降维 → 3×3 → 1×1 升维，用于 ResNet-50/101/152，减少计算量。

**预激活（pre-activation）**：把 BN-ReLU 放到卷积之前（$x_{l+1} = x_l + F(\mathrm{BN\text{-}ReLU}(x_l))$），恒等通路完全干净，进一步改善深层训练（He et al., 2016b）。

### 2.6 一个重要视角：隐式集成

把 $L$ 个残差块展开，输出等于所有"块的子集路径"之和，路径数随深度指数增长——ResNet 可看作对指数多个浅网络的隐式集成，这也是它对丢弃部分层不敏感、表现稳健的原因之一。

## 3. 两种"残差"的关系

| 场景 | 残差指什么 | 式子 | 作用 |
|---|---|---|---|
| 回归 / 统计 | 观测值与预测值之差 | $e = y - \hat{y}$ | 衡量拟合好坏、模型诊断、GBDT 的拟合目标 |
| 深度学习（ResNet） | 网络层要学的"相对输入的增量" | $F(x) = H(x) - x$ | 易优化、梯度直通、可堆深 |

共同直觉：**不直接预测答案，而预测还需要修正多少**。数学上都是"目标减去参考"，只是一个用于"评价"，一个用于"建模"。

## 4. 常见误区

1. **残差 ≠ 误差 ≠ 偏差**：误差相对真值不可观测；"偏差"是偏差-方差分解里的 $E[\hat{f}] - f$，是模型族的系统性偏离，与样本残差不是一回事。
2. **残差连接不是"直接相加就完事"**：维度不一致必须投影；且加法要求形状完全对齐，这是实现时最常见的 bug。
3. **残差块 ≠ 集成**：显式训练时仍是单个网络，只是展开后等价于路径集成。
4. **梯度分析里的 $I$ 是近似直觉**：严格地说逐层雅可比含 $I + \partial F/\partial x$，$\partial F/\partial x$ 可正可负，"梯度不消失"是经验上成立的机制，不是数学保证。

1. 用最小二乘拟合一个带截距的线性模型，验证残差均值为 0、$X^\top e = 0$（示例代码第 1 部分）。
